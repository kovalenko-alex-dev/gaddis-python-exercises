# Изучение основ Python (по книге Тони Гэдиса)

Репозиторий для ежедневной практики, закрепления базового синтаксиса, алгоритмов и ключевых инструментов языка Python. Все задачи написаны вручную, структурированы по функциям и снабжены точкой входа `if __name__ == '__main__':`.

## Прогресс и примеры задач

### 1. Симуляция работы с HTTP статус-кодами
* **Файл:** `server_status_simulator.py`
* **Что демонстрирует:** Использование модуля `random`, ветвление `if-else`, работу со счетчиками и возврат булевых значений (`True`/`False`) из пользовательских функций.
* **Логика:** Скрипт имитирует 20 сетевых запросов, генерируя случайные HTTP-ответы, сортирует их на успешные/ошибочные и выводит финальную статистику.

### 2. Проверка текста на стоп-слова
* **Файл:** `secret_word_detector.py`
* **Что демонстрирует:** Организацию бесконечных интерактивных циклов `while True` с контролируемым выходом через `break`, а также применение оператора `in` для поиска подстроки в строке.
* **Логика:** Запрашивает у пользователя текст, проверяет наличие ключевого слова `'secret'` и предлагает повторить операцию.

### 3. Накопитель отчетов со "стражевым значением" и записью в файл
* **Файл:** `report_accumulator.py`
* **Что демонстрирует:** 
  * Алгоритм циклического ввода с предварительным чтением данных (`priming read`).
  * Безопасную работу с файлами в режиме дозаписи (`'a'`) через контекстный менеджер `with`.
  * Перехват ошибок ввода пользователя с помощью конструкции `try-except-finally`.
* **Логика:** Программа циклически принимает числовые значения отчетов, логирует их в файл `filename.txt` и суммирует. Ввод числа `0` служит сигналом (sentinel) для завершения работы и вывода итоговой суммы.

### 4. Безопасное чтение файлов конфигурации / кэша
* **Файл:** `safe_config_reader.py`
* **Что демонстрирует:** Базовую обработку исключений при работе с внешними ресурсами, изоляцию потенциально опасного кода открытия файлов.
* **Логика:** Пытается прочитать данные из локального файла кэша `subscribes.txt`. Если файл физически отсутствует на диске, программа не падает аварийно, а перехватывает ошибку `FileNotFoundError`, мягко переключаясь на резервный режим работы. Блок `finally` гарантирует выполнение финального уведомления при любом исходе.

## Как запустить любой скрипт
1. Склонируйте репозиторий.
2. Откройте терминал в папке проекта.
3. Запустите интересующий файл через команду:
   ```bash
   python название_файла.py
   ```
